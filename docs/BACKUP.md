# نسخ احتياطي — WADI ERP

## الطريقة
شغّل `scripts/backup.sh` مع متغير `SUPABASE_PAT` (رمز الوصول الشخصي من لوحة Supabase).
يسكب كل جدول في ملف JSON داخل مجلد مؤرخ. شغّال على الخطة المجانية بدون أي تكلفة.

```
SUPABASE_PAT=xxxx ./scripts/backup.sh
```

## التوصية
- تشغيل يومي (cron) والاحتفاظ بآخر 30 نسخة.
- ملفات المرفقات في Storage (bucket: docs) تُحمّل منفصلة عند الحاجة من لوحة Supabase.
- للاسترجاع: تُعاد إدخال الجداول بترتيب المفاتيح الأجنبية (accounts ← branches ← ... ← audit_log).

## ملاحظة
خطة Supabase المجانية لا تتضمن نسخاً تلقائية من جانبهم، لذا هذا السكربت هو خط الدفاع.
